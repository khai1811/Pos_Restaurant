# Hệ Thống POS Quản Lý Nhà Hàng
 
Dự án phần mềm quản lý nhà hàng toàn diện, tối ưu hóa quy trình từ lúc khách gọi món, điều phối bếp đến khâu thanh toán và báo cáo.

## 🚀 Tính năng nổi bật
* **Quản lý Bán hàng (POS):** Quản lý sơ đồ bàn trực quan, gọi món nhanh, thao tác chuyển/gộp bàn.
* **Hệ thống KDS (Bếp):** Nhận order realtime từ thu ngân & phục vụ, cập nhật trạng thái nấu từng món.
* **Thanh toán Đa kênh:** Hỗ trợ Tiền mặt, VietQR, Thẻ POS, Tách kênh (Split). Xử lý linh hoạt chiết khấu và thuế VAT 8%.
* **Báo cáo & Lịch sử:** Tra cứu hóa đơn đồng bộ, thao tác hoàn tiền (Refund), in lại bill, xuất báo cáo Excel và in Z-Report chốt ca.

## 🛠️ Tech Stack
* **Frontend:** React, Tailwind CSS
* **Backend:** Node.js, Prisma ORM
* **Khác:** Tích hợp giao diện in ấn `@media print` cho máy in nhiệt 80mm.

## ⚙️ Hướng dẫn cài đặt
1. Clone dự án: `git clone <link-repo>`
2. Cài đặt thư viện: `npm install`
3. Khởi chạy dự án: `npm run dev`
